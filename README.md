# Práctica de Git y GitHub — PEL

Repositorio para practicar el flujo básico de trabajo con Git y GitHub:

1. Crear el repositorio remoto.
2. Clonarlo y trabajar en una copia local.
3. Editar archivos y guardar los cambios en commits.
4. Subir los commits a GitHub.

El archivo `ejemplo.py` contiene una pequeña prueba de edición local. En `comandos-git.md` se explica para qué sirven los comandos vistos en clase.
